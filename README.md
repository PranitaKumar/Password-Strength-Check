# Password-Strength-Check
#A real-time password strength evaluation tool built with Python and Tkinter. This project provides feedback on the strength of your password using a progress bar and color-coded messages.

#Features
Real-time Strength Analysis: Evaluates the password while you type.
Color-Coded Feedback: Red for weak, orange for moderate, green for strong.
Criteria-Based Scoring: Checks for length, uppercase letters, numbers, and special characters.
User-Friendly Interface: Simple and clean design with a progress bar for visual feedback.
